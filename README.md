# terminal-config
-> Fork code for every new company

## neovim
1. Brew install neovim
2. Configure `.vimrc`

## zshrc 
1. Install and configure powerline10k
2. Configure `.zshrc`

## tmux
1. Create and configure `.tmux.conf`
 
## neofetch
_neofetch config with custom display_

1. Add duck ascii `/etc/neofetch/duck-half.ansii`
2. Replace `~/.config/neofetch/config.conf`
3. Replace `opt/homebrew/bin/neofetch``
